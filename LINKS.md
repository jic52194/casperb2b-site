Generated by `npm run build` (from scripts/ia.mjs and data/keywords.json).

## Rules
- Header menu grouped by visitor goal (below). Mobile: same groups in the drawer.
- Every page: breadcrumb (Home › topic hub › section › page), a "Related in <topic>" block (same-topic siblings + the hub), and a "Your next best step" block linking the most relevant service, free tool, article and the booking page, plus the trust block.
- One primary CTA per page: "Book My 15-Minute Fit Call" → /contact?topic=<topic> (header button, in-page buttons, sticky mobile bar, footer). Other buttons are secondary. Tools convert inside the tool with a short form.
- Every page is one click from booking (header CTA + sticky mobile bar) — `npm run check` fails otherwise.
- Topic hubs list every page in their topic, so every page is within two clicks of the menu.
